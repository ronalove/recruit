# shorty

Link shortener in TypeScript on Bun, no framework. See README.md for the API.

- `bun test` before handing work back; tests live in `test/`.
- Slugs are 4 to 8 characters from `src/slug.ts`; never change existing ones.
- The page in `public/` is plain HTML and CSS, no build step.
- Open work is listed in TODO.md.
